> **"XD – Where Accounting Meets AI"**

**XD ERP** هو نظام تخطيط موارد مؤسسات (ERP) احترافي ومتكامل، مبني بالكامل بلغة **Python**. يقدم دورة محاسبية كاملة، إدارة المخزون، المبيعات، المشتريات، الموارد البشرية، **26 وحدة وظيفية**، و **مساعد ذكي بـ 9 وظائف** تحليلية وتنبؤية مدعوم بـ Groq AI. يتميز بواجهة **زجاجية (Glassmorphism) فخمة وعصرية**، وحماية عمليات مالية كاملة، وفصل تام بين طبقات الخدمات والواجهة – جاهز للاستخدام الفعلي في الشركات الصغيرة والمتوسطة.

## 🚀 الميزات الرئيسية

### 📊 المحاسبة والمالية
- **دورة محاسبية كاملة** – قيود يومية، أستاذ عام، ميزان مراجعة
- **شجرة حسابات** – هرمية 4 مستويات (أصول، خصوم، حقوق ملكية، إيرادات، مصروفات)
- **قائمة الدخل والميزانية العمومية** – تُنشأ تلقائياً من القيود
- **إغلاق الفترات** – قفل/فتح الشهور والسنوات المالية
- **قيد إغلاق الحسابات** – إغلاق تلقائي للإيرادات والمصروفات
- **FIFO المخزون** – تتبع الدفعات والتكلفة تلقائياً
- **💱 تعدد العملات** – إدارة العملات وأسعار الصرف، فواتير بعملات متعددة
- **🏦 التعاملات البنكية** – حسابات بنكية، حركات، مصالحات، أرصدة
- **🏢 مراكز التكلفة** – إدارة هرمية، توزيع القيود، موازنات تقديرية، تحليل انحرافات
- **🧾 ضريبة القيمة المضافة (VAT)** – حساب تلقائي، تقارير إقرار

### 🛒 العمليات
- **المبيعات** – فواتير بيع، عملاء، خصم تلقائي من المخزون
- **المشتريات** – فواتير شراء، موردين، إضافة تلقائية للمخزون
- **مرتجعات البضاعة** – مرتجع مبيعات ومشتريات
- **المخزون** – حركات، تنبيهات نقص، منتجات
- **CRM** – عملاء محتملين، فرص بيعية، تفاعلات

### 👥 إدارة الأعمال
- **الموارد البشرية** – موظفين، حضور وانصراف
- **كشف الرواتب** – إعداد وتشغيل الرواتب مع قيد تلقائي
- **الأصول الثابتة** – إهلاك قسط ثابت شهري بقيد تلقائي
- **📎 المرفقات** – رفع وتحميل الملفات وربطها بأي سجل

### 🛡️ الأمان والامتثال
- **سجل التدقيق** – تتبع كل عملية (إنشاء/تعديل/حذف) مع اسم المستخدم والتاريخ
- **الصلاحيات** – 4 أدوار (مدير، محاسب، أمين مخزن، كاشير)
- **نسخ احتياطي** – إنشاء وتحميل (ZIP) واستعادة النسخ
- **إدارة العمليات** – جميع العمليات المالية تستخدم `BEGIN/COMMIT/ROLLBACK`

### 🤖 المساعد الذكي (9 وظائف)
| التبويب | الوظيفة |
|---------|----------|
| 🧠 مساعد محاسبي | محادثة عميقة مع ملخصات الأعمال الحية |
| 📊 محلل مالي | تحليل شامل للنسب المالية مع توصيات |
| 📦 توقع المخزون | تحليل المنتجات المتوقع نفادها |
| 💬 شات الموظفين | استفسارات الرواتب والمعلومات الشخصية |
| 📝 قيود تلقائية | نص عربي → قيد محاسبي مركب |
| 🔍 كشف الاحتيال | مراجعة القيود واكتشاف الأنماط المشبوهة |
| 🔮 تنبؤات مستقبلية | توقعات المبيعات والتدفق النقدي |
| 📈 تحليل عميق | تقرير مخصص يغطي جوانب يختارها المستخدم |
| 🎯 مراكز تكلفة | تحليل أداء، مقارنة، توقع مصروفات، انحرافات موازنات |

**🧠 آلية عمل الذكاء الاصطناعي (AI Data Layer):**
- **طبقة الملخصات الذكية:** بدلاً من إرسال قاعدة البيانات الخام، يتم تجميع 6 لقطات (Financial, Inventory, Business, HR, Trends, Cost Centers) في كائن JSON صغير (50-150 سطر).
- **تحسينات الأداء:** تخزين مؤقت (Cache)، التحقق من صحة البيانات (Validation)، وضغط الذاكرة (Memory Compression).

### 🎨 التصميم والتجربة
- **واجهة زجاجية (Glassmorphism)** – تصميم عصري بتأثيرات الضبابية
- **متجاوب** – يعمل على المتصفح والجوال
- **عربي أولاً** – دعم كامل للغة العربية
- **لوحة معلومات** – بطاقات KPIs، رسوم بيانية، تنبيهات فورية، أنشطة
- **قائمة جانبية احترافية** – 6 مجموعات منظمة بأيقونات

```

├── app.py                       # المدخل الرئيسي والقائمة الجانبية
├── database.py                  # 25+ جدول SQLite
├── requirements.txt             # المكتبات المطلوبة
├── services/                    # طبقة منطق الأعمال (26 خدمة)
│   ├── accounting_service.py    # الحسابات والقيود
│   ├── ai_service.py            # المساعد الذكي + AI Data Layer
│   ├── cost_center_service.py   # مراكز التكلفة
│   ├── currency_service.py      # العملات وأسعار الصرف
│   ├── bank_service.py          # التعاملات البنكية
│   ├── attachment_service.py    # المرفقات
│   └── ...                      # باقي الخدمات
├── ui/                          # طبقة واجهة المستخدم (26 واجهة)
│   ├── accounting_ui.py         # واجهة الحسابات
│   ├── ai_ui.py                 # واجهة المساعد الذكي (9 تبويبات)
│   ├── dashboard_ui.py          # لوحة المعلومات
│   ├── auth_ui.py               # تسجيل الدخول
│   └── ...                      # باقي الواجهات
├── api/                         # طبقة API (FastAPI - 27 نقطة نهاية)
└── backups/                     # مجلد النسخ الاحتياطية

```

**فصل تام للطبقات** – كل وحدة مقسمة إلى خدمة (Services) وواجهة (UI). هذا يجعل النظام:
- ✅ سهل الصيانة

- ✅ جاهز للتحويل إلى API
