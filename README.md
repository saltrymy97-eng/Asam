> **"إدارة ذكية .. قرارات واثقة"**

**حوكمة ERP** هو نظام تخطيط موارد مؤسسات احترافي ومتكامل، مبني بلغة **Python**. يقدم دورة محاسبية كاملة بتكامل FIFO وتكلفة البضاعة المباعة (COGS)، مع إدارة المخزون، المبيعات، المشتريات، الموارد البشرية، **31 وحدة وظيفية**، و **مساعد ذكي بـ 9 وظائف** تحليلية وتنبؤية مدعوم بـ Groq AI. يتميز بواجهة **زجاجية (Glassmorphism) فخمة وعصرية**، وحماية عمليات مالية كاملة بنظام atomicity (الكل أو لا شيء)، وفصل تام بين طبقات الخدمات والواجهة – جاهز للاستخدام الفعلي في الشركات الصغيرة والمتوسطة.

## 🚀 الميزات الرئيسية

### 📊 المحاسبة والمالية
- **دورة محاسبية كاملة** – قيود يومية تلقائية، أستاذ عام، ميزان مراجعة
- **FIFO المخزون** – تتبع الدفعات والتكلفة تلقائياً مع تكلفة البضاعة المباعة (COGS)
- **شجرة حسابات** – هرمية 4 مستويات (أصول، خصوم، حقوق ملكية، إيرادات، مصروفات)
- **قائمة الدخل والميزانية العمومية** – تُنشأ تلقائياً من القيود
- **إغلاق الفترات** – قفل/فتح الشهور والسنوات المالية
- **💱 تعدد العملات** – إدارة العملات وأسعار الصرف، فواتير بعملات متعددة، فروق أسعار الصرف
- **🏦 التعاملات البنكية** – حسابات بنكية، حركات، مصالحات، أرصدة
- **🏢 مراكز التكلفة** – إدارة هرمية، توزيع القيود، موازنات تقديرية، تحليل انحرافات
- **🧾 ضريبة القيمة المضافة (VAT)** – حساب تلقائي، تقارير إقرار

### 🛒 العمليات
- **المبيعات** – فواتير بيع، عملاء، خصم تلقائي من المخزون، حساب COGS
- **المشتريات** – فواتير شراء، موردين، إضافة تلقائية للمخزون، دفعات FIFO
- **مرتجعات البضاعة** – مرتجع مبيعات ومشتريات مع FIFO عكسي وقيود تلقائية
- **المخزون** – حركات، تنبيهات نقص، تسويات مخزنية (جرد)، حماية من الصرف الزائد
- **CRM** – عملاء محتملين، فرص بيعية، تفاعلات
- **💵 سندات القبض والصرف** – إدارة المقبوضات والمدفوعات مع قيود تلقائية
- **🧾 المصروفات التشغيلية** – تسجيل المصاريف الإدارية (نقداً أو آجلاً)
- **📋 الأرصدة الافتتاحية** – إدخال أرصدة بداية المدة للحسابات والمخزون

### 👥 إدارة الأعمال
- **الموارد البشرية** – موظفين، حضور وانصراف
- **كشف الرواتب** – إعداد وتشغيل الرواتب مع قيد تلقائي
- **الأصول الثابتة** – إهلاك قسط ثابت شهري بقيد تلقائي
- **📎 المرفقات** – رفع وتحميل الملفات وربطها بأي سجل

### 🛡️ الأمان والامتثال
- **سجل التدقيق** – تتبع كل عملية مع اسم المستخدم والتاريخ
- **الصلاحيات** – 4 أدوار (مدير، محاسب، أمين مخزن، كاشير) مع أذونات تفصيلية
- **نسخ احتياطي** – إنشاء وتحميل (ZIP) واستعادة النسخ
- **Atomicity** – جميع العمليات المالية تستخدم `BEGIN/COMMIT/ROLLBACK` (الكل أو لا شيء)

### 🤖 المساعد الذكي (9 وظائف)
| التبويب | الوظيفة |
|---------|----------|
| 🧠 مساعد محاسبي | محادثة عميقة مع ملخصات الأعمال الحية |
| 📊 محلل مالي | تحليل شامل للنسب المالية مع توصيات |
| 📦 توقع المخزون | تحليل المنتجات المتوقع نفادها |
| 💬 شات الموظفين | استفسارات الرواتب والمعلومات الشخصية |
| 📝 قيود تلقائية | نص عربي → قيد محاسبي مركب |
| 🔍 كشف الاحتيال | مراجعة القيود واكتشاف الأنماط المشبوهة |
| 🔮 تنبؤات مستقبلية | توقعات المبيعات والتدفق النقدي |
| 📈 تحليل عميق | تقرير مخصص يغطي جوانب يختارها المستخدم |
| 🎯 مراكز تكلفة | تحليل أداء، مقارنة، توقع مصروفات |
